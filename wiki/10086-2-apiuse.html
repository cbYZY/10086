班级Tools API开放支持

通过API连接随机抽取 进阶玩法【全平台】

全平台支持 编号 10086-2-apiuse

一个网址就能随机抽人抽组，浏览器、手机、命令行、快捷指令全能用

⚠️ 必须用 server.py 启动服务！纯静态服务器（如 python -m http.server）无法响应动态 API 路径，会返回 404。正确启动方式：在站点根目录执行 python server.py（端口默认 8137），所有页面 + API 同时生效。

Tip：API 返回的是纯文本结果，任何能打开网址或发送网络请求的平台都可以直接使用。名单文件为 chou/api/x.txt，每次请求实时读取，改完即生效。

一、工作原理

API（应用程序接口）就是一个「网址即服务」：你向服务器发起一次访问（HTTP GET 请求），服务器收到后实时读取名单，用洗牌算法随机抽取，再把结果作为纯文本直接返回给你。整个过程不打开任何页面、不显示任何界面——网址本身就是「抽取按钮」，返回的内容本身就是「抽取结果」。

每次请求都是一次全新的随机抽取；同一次请求内抽出的名字或小组不会重复。名单变动（编辑 chou/api/x.txt）立即生效，无需重启服务。

二、接口格式

/chou/api/{type}/{x}
参数取值说明
typehuman / teamhuman 抽个人，team 抽小组
x正整数抽取个数；超过名单总数时按总数返回

三、可复制的请求地址（点开即出结果）

抽 1 名学生：

http://10086.csningxiang.com/chou/api/human/1

抽 3 名学生：

http://10086.csningxiang.com/chou/api/human/3

抽 2 个小组：

http://10086.csningxiang.com/chou/api/team/2

Tip：若主域名无效，把开头换成备用域名 classtools.csningxiang.com 即可，路径不变。

http://classtools.csningxiang.com/chou/api/human/1

四、返回结果说明

抽人（human/3）返回示例——每行一个名字：

成诺 傅子纯 李钰轩

抽组（team/2）返回示例——每行「组名：成员列表」：

家贝队：周家贝、任语涵、傅子纯、朱梓汐、李恩璇、刘浠辰、陈俊宇 煜祺队：贺煜祺、谢薇怡、唐嘉阳、周泽文、陈紫萱、易子源、赵璇

五、各平台操作方法

1. 浏览器（最简单）：把上面的地址粘贴到地址栏访问，或点开链接，结果直接显示在页面上。

2. Windows / Mac 命令行：系统自带 curl，打开终端输入（Win10 及以上自带）：

curl http://10086.csningxiang.com/chou/api/human/3

3. iOS 快捷指令：新建快捷指令 → 添加「获取 URL 内容」→ 粘贴请求地址 → 运行后结果即文本内容，可配合「显示结果」或「朗读文本」实现语音抽人。

4. Android / 其他：任何支持自定义 URL 的工具（Tasker、MacroDroid、小程序云函数、自己写的脚本等）发起 GET 请求即可，返回文本就是结果。

六、错误提示含义

状态含义与解决
400抽取个数不是正整数（如 human/0），改为 1、2、3…
404地址拼写错误，检查 type 是否为 human 或 team、路径是否为 /chou/api/ 开头
500服务器名单文件缺失或为空，检查 chou/api/x.txt

Tip：自定义名单只需编辑服务器上的 chou/api/x.txt——以 # 结尾的行是组名（如「家贝队#」），其下为该组成员；保存后立刻生效，抽人与抽组同步更新。
